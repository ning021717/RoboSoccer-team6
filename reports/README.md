# Evidence summaries

The CSV files in this directory are versioned summaries exported from real local
Webots evidence. Read [DATA_PROVENANCE.md](DATA_PROVENANCE.md) before using
them for comparisons or portfolio claims.

- `p3_kick_repeatability_summary.csv`: three deterministic physical-kick repeats
  at one fixed calibrated pose.
- `p0_camera_boundary_regression_summary.csv`: before/after safety regression;
  this is not an equal-duration performance comparison.
